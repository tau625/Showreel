# 叙事骨架（generic 模式按题材选）

用在 Step 4。`promo` 模式不用这张表，走固定的「抛问 → 痛点 → 卖点前置 → 流程演示×N → 收尾」。

## 选材

| 题材 | 结构 | 段数参考 |
|---|---|---|
| 科普讲解 | 抛问/现象 → 常见误解 → 原理拆解（分小段，每段只讲一个机制）→ 例证 → 要点回顾 → 结论 | 6-10 |
| 教程/演示 | 目标（学完能做什么）→ 准备 → 步骤×N → 验证 → 常见坑 → 下一步 | 5-12 |
| 数据报告 | 结论先行 → 指标1 → 指标2 → 指标3 → 交叉发现 → 局限与建议 | 5-8 |
| 活动/招新 | 钩子（3 秒内）→ 是什么 → 为什么值得来 → 怎么参与 → 时间地点 | 4-6 |
| 观点/评论 | 反常识结论 → 常识是什么 → 为什么错 → 证据 → 重新表述结论 | 5-7 |

## 与 promo 的实质差异

| 维度 | promo | generic |
|---|---|---|
| 画面主力 | 真实截图 / 界面复刻 | 代码动画 / 数据图表 / 示意图（通常没有界面可截） |
| 时长 | 60s–3min | 30s–8min，科普类普遍更长 |
| 配音语速 | `-10%`（沉稳） | 科普可 `-5%`，教程 `-8%`，快节奏活动 `+0%` |
| 字幕 | 可小可雅（34px） | 教程/科普建议 40px，观众常静音看 |
| 收尾 | 开源许可 + CTA | 科普加「要点回顾」；教程加「常见坑」；报告加「局限」 |
| 时间戳章节 | 有则更好 | **必需**，观众跳着看 |

## 分段执行的硬规则

- 每段只讲一件事。一段塞两个机制 = 观众记不住，且 `extra` 不够演示。
- 讲解类每段都要有"看完了能复述出来的那句话"，把它放进 `keyPoints` 做成视觉锚点。
- 关键操作要有视觉高亮（框选 / 箭头 / 放大），纯口播"点这里"无效。
- 命令行类内容用等宽字体组件（`FONT.mono`），不要用截图糊字。
- 数据报告里，配音只在关键节点出现，其余留白给图表动画，不要全程念数字。
