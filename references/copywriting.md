# 各平台发布文案模板

## §1 promo 模式

### 小红书（标题 ≤20 字，正文 ≤1000 字）

标题三选一，按投放人群挑：

1. `{痛点场景} + {利益点} + 一个 emoji` ← 搜索流量最好，默认选这个
2. `{人群} + {场景} + 一个工具就够了` ← 打垂直人群
3. `{权威背书} + {核心动作}` ← 强调官方/权威来源

```
标题：教材PDF免费下，不用网盘会员了📚

正文：
还在到处找教材PDF？网盘会员、限速、广告，受够了🙅

「书到了」——国家中小学智慧教育平台教材下载工具

✅ 完全免费开源，个人学习/教学备课随便用
✅ 数据与官方平台实时一致，新书同步最快
✅ 学段→年级→科目→版本→册次，点几下就找到
✅ 多本勾选批量下载，进度一目了然
✅ Windows / macOS / Linux 都能用，安装包只有几十 MB

GitHub 搜「{项目名}」就能找到，链接放评论区📌

⚠️ 工具本身不含任何教材，版权归官方平台及出版机构所有，仅供个人学习研究使用

#教师备课 #教材PDF #中小学教师 #免费工具 #开源项目 #效率工具 #备课资源 #教育技术
```
（这是「书到了」的成稿实例；换项目时保结构、换内容，标签跟着目标人群换。）

规则：
- 站外链接放**评论区第一条**，正文写"链接放评论区"引导（正文放外链会限流）
- 标签 6-8 个，前两个选搜索量大的泛词，后面补精准长尾
- 正文太长掉阅读：只贴开场两行 + 卖点 + 合规那行，完整版放**置顶评论**
- 卖点用 `✅` 起行，每条一行，不写长句

## §2 generic 模式

### 科普 / 教程：B站简介

```
{一句话：看完你能搞懂/学会什么}

⏱ 章节
0:00 {现象/目标}
0:35 {误解1}
1:20 {原理A}
……

{补充资料 / 参考链接}
{音乐署名}
```

科普类时间戳**必需**，观众跳看是常态。章节名要能独立表意（"为什么 XXX 不成立"，而不是"第三部分"）。

### 视频号 / 抖音

- 竖版优先
- 前三秒必须有钩子：提问或反常识结论，不要"大家好今天我们来…"
- 字幕烧进画面（多数人静音刷）
- 文案 2-3 行就够，标签 3-5 个

### 通用替换位

写文案时按这个顺序填：

1. 痛点/钩子一句话（制造共鸣或认知冲突）
2. 主题一句话定位（它是什么）
3. 3-5 条卖点或要点（`✅` 起行）
4. 获取方式 / CTA
5. ⚠️ 合规或版权声明（有则必写，涉及第三方内容时是硬要求）
6. 标签
